# Box Hub M2 — Wi-Fi et mises à jour

- La box se connecte uniquement en Wi-Fi **2,4 GHz** (pas en 5 GHz) ; un câble Ethernet est aussi possible.
- Les **mises à jour** sont automatiques, la nuit vers **3 h** ; ne pas débrancher la box quand le voyant est violet.
- Après une mise à jour, si un appareil n'apparaît plus, redémarrez la box (débrancher 30 secondes).
- Réinitialisation complète : bouton *Reset* 15 secondes ; tous les appareils devront être appairés de nouveau.
