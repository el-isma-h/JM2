# Application mobile Maison Connectée

- Compatible **iOS 17** et versions suivantes, **Android 12** et versions suivantes.
- Mot de passe oublié : écran de connexion → *Mot de passe oublié* ; le lien reçu par e-mail est valable **1 heure**.
- Notifications absentes : vérifiez qu'elles sont autorisées dans les réglages du téléphone et que le mode économie d'énergie n'est pas actif.
- Un même logement peut être partagé avec 5 membres de la famille (*Réglages → Membres*).
