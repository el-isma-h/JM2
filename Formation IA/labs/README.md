# Labs pratiques — Formation IA (NF-IA-150)

Huit kits prêts à l'emploi, un par leçon projet. Chacun suit le même format : un `README.md` (objectif, contenu, énoncé, critères de réussite repris de la leçon, mission documentation), un **mode sans clé** qui fait tout tourner hors ligne, un `.env.example`, et selon le cas un **starter** à compléter, une **solution** et des tests automatisés. Aucun kit ne contient de clé API ni de dépendances installées (`node_modules`, `.venv`).

**Sécurité offensive** : aucun lab n'est fourni. L'audit de sécurité d'une application IA se pratique avec l'atelier de la leçon [L110 — Audit de sécurité d'une application IA](../niveaux/N3-developpeur/M23-securite-des-applications-llm/L110-audit-de-securite-d-une-application-ia-atelier.md), dans un environnement isolé et sous mandat écrit.
